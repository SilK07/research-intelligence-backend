# Research Paper Analyzer

Backend system for parsing, processing, and analyzing long academic research papers.

## Features
- Upload and parse academic PDFs
- Chunk and process long documents
- Generate structured summaries and insights
- Modular backend design for easy extension

## Tech Stack
- Python
- Fast API
- LLM APIs
- Modular service-based architecture

## API Endpoints (Example)
- POST /analyze-paper
- GET /health


## How to Run
```bash
pip install -r requirements.txt
python app/main.py
```
